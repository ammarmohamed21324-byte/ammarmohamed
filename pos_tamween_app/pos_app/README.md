# نظام نقاط بيع (POS) لمحل التموين

برنامج ديسكتوب لويندوز بيدعم:
- بيع نقدي عادي + بيع بالبطاقة التموينية (دعم) مع سعر مختلف للصنف المدعم
- قارئ باركود (يعمل تلقائيًا كأي لوحة مفاتيح، مفيش إعداد إضافي مطلوب)
- طباعة فاتورة على طابعة حرارية
- قاعدة بيانات مركزية (MySQL) بحيث كل أجهزة/فروع المحل تشوف نفس المخزون والمبيعات لحظيًا
- تقارير مبيعات يومية، أصناف الأكثر مبيعًا، وتنبيه نواقص المخزون

## ⚠️ ملحوظة مهمة جدًا
البرنامج ده **مش متصل رسميًا بمنظومة الدعم التمويني الحكومية**. لا يوجد وصول لأي جهة خارجية (غير حكومية) لمنظومة خصم بطاقات التموين الفعلية — الوصول ده مقصور على الأجهزة والتراخيص الرسمية من وزارة التموين. البرنامج بيوفرلك بس **سجل داخلي** لتتبع مبيعات الأصناف المدعمة والبطاقات لأغراض إدارة المحل ومتابعة حساباتك.

## الخطوة 1: تجهيز السيرفر (جهاز واحد بس في المحل)

اختار جهاز واحد (يفضل يكون شغال طول الوقت) يكون بمثابة "السيرفر" اللي فيه قاعدة البيانات، والباقي يتصلوا بيه.

1. نزّل ثبّت **MySQL Community Server** من:
   https://dev.mysql.com/downloads/mysql/
   وقت التثبيت، اختار Server + Workbench، وحدد باسورد لمستخدم root واحفظه.

2. افتح **MySQL Workbench** واتصل بالسيرفر، وشغّل ملف `schema.sql` المرفق (افتحه ونفذه بالكامل Execute).
   ده هينشئ قاعدة البيانات وكل الجداول ومستخدم أدمن افتراضي.

3. اعمل مستخدم مخصص للبرنامج (بدل استخدام root مباشرة) بتشغيل الأوامر دي في Workbench:
   ```sql
   CREATE USER 'pos_user'@'%' IDENTIFIED BY 'ضع_باسورد_قوي_هنا';
   GRANT ALL PRIVILEGES ON pos_tamween.* TO 'pos_user'@'%';
   FLUSH PRIVILEGES;
   ```

4. اعرف الـ IP الخاص بجهاز السيرفر على الشبكة المحلية (شغّل `ipconfig` في cmd وشوف "IPv4 Address"، مثال: 192.168.1.10).
   لازم يكون ثابت (تقدر تثبته من إعدادات الراوتر - DHCP Reservation) عشان مايتغيرش كل مرة.

5. تأكد إن الـ Firewall في ويندوز مسموح فيه بمنفذ MySQL (3306) من الشبكة المحلية.

## الخطوة 2: بناء ملف exe (على أي جهاز فيه Windows + Python)

1. ثبّت Python (نسخة 3.10 أو أحدث) من https://python.org — **مهم جدًا** تعمل ✅ على "Add Python to PATH" وقت التثبيت.
2. افتح مجلد المشروع، دوس دبل كليك على **`build.bat`**.
3. السكريبت هيثبت المكتبات المطلوبة تلقائيًا ويبني الملف.
4. هتلاقي الناتج في: `dist\pos_tamween.exe`

انسخ ملف `pos_tamween.exe` ده لأي جهاز تاني في المحل (الكاشير، جهاز المكتب...). كل جهاز محتاج بايثون؟ **لأ** — الـ exe ده شغال لوحده من غير ما تثبت بايثون على الجهاز اللي هيشغله، لكن أنت محتاج بايثون بس على الجهاز اللي بنيت عليه الملف.

## الخطوة 3: إعداد كل جهاز

1. شغّل `pos_tamween.exe`. أول مرة هيتعمل بجانبه ملف `config.json` بإعدادات افتراضية.
2. سجل دخول بالحساب الافتراضي: **admin** / **admin123** (غيّر الباسورد بعدين من قاعدة البيانات لو حبيت).
3. روح لتبويب **الإعدادات** واكتب:
   - عنوان السيرفر (IP) اللي عملته في الخطوة 1
   - مستخدم/باسورد قاعدة البيانات اللي أنشأتهم
4. دوس **اختبار الاتصال بقاعدة البيانات** للتأكد إن كل حاجة تمام، بعدين **حفظ الإعدادات**، وأعد تشغيل البرنامج.
5. كرر نفس الخطوات (3،4) على كل جهاز تاني في المحل، لكن كلهم يشيروا لنفس الـ IP بتاع السيرفر.

## الخطوة 4: الطابعة الحرارية

في تبويب الإعدادات اختار طريقة الطباعة:
- **الطابعة الافتراضية في ويندوز (الأسهل)**: ثبّت تعريف الطابعة العادي اللي بييجي معاها، واخليها "الطابعة الافتراضية" في ويندوز من لوحة التحكم. البرنامج هيبعتلها الفاتورة مباشرة.
- **USB مباشر (escpos)**: لو طابعتك مش بتتعرف كطابعة عادية على ويندوز، محتاج تنزل برنامج **Zadig** (https://zadig.akeo.ie) وتعمل بيه تعريف WinUSB للطابعة، وتكتب Vendor ID / Product ID بتاعتها في الإعدادات (تقدر تلاقيهم من Device Manager).

## استخدام الباركود

قارئ الباركود بيشتغل تلقائيًا من غير إعداد — هو بيتصرف كأنه لوحة مفاتيح بيكتب الرقم ويضغط Enter، والبرنامج بيستقبله في مربع "إدخال / مسح باركود" في شاشة البيع مباشرة.

## هيكل المشروع

```
pos_app/
├── main.py              نقطة تشغيل البرنامج
├── config.py            إدارة إعدادات البرنامج (config.json)
├── database.py          كل التعامل مع قاعدة البيانات MySQL
├── printer.py           طباعة الفواتير
├── schema.sql           هيكل قاعدة البيانات (يُشغّل مرة واحدة على السيرفر)
├── requirements.txt     المكتبات المطلوبة
├── build.bat            سكريبت بناء ملف exe
└── ui/
    ├── login_window.py  شاشة تسجيل الدخول
    ├── main_window.py   النافذة الرئيسية (التبويبات)
    ├── pos_tab.py        شاشة البيع
    ├── inventory_tab.py  إدارة المخزون والأصناف
    ├── ration_tab.py     إدارة بطاقات التموين
    ├── reports_tab.py    التقارير
    └── settings_tab.py   الإعدادات
```

## أفكار لتطوير لاحق
- صلاحيات أدق لكل مستخدم (كاشير يقدر يبيع بس، أدمن يقدر يعدل الأسعار)
- شاشة "توريد بضاعة" لزيادة المخزون مع تسجيل المورد والفاتورة
- نسخة احتياطية تلقائية لقاعدة البيانات (mysqldump مجدول يوميًا)
- ربط مع أي واجهة رسمية تتيحها وزارة التموين لاحقًا لو توفرت لأصحاب المحال
